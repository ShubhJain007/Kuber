# Kuber — interactive demo

Static Hugging Face Space serving the Kuber project page (`index.html`) and the interactive
ground-truth-vs-prediction 3D viewer (`demo.html`). No backend / no compute — the viewer ships
its data embedded and renders client-side with WebGL, so this runs on the free Static Space tier.

Source & full repo: https://github.com/ShubhJain007/Kuber
